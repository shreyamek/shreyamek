# Hi, I'm Shreya

I started building websites in high school and never really stopped. These days it's mostly Python, SQL and Java for work (Airflow, Spark and AWS), and React and TypeScript when I want to build something people can click on.

## Things I've made

**Artemis Assist.** A wearable safety device with a phone app, built in 24 hours at WeHack 2024. It listens for sounds that could mean someone is in danger. The audio model reached 94% accuracy, and the project won the L3Harris challenge.

**[Doc](https://github.com/shreyamek/hackuta-2025).** A health assistant from HackUTA 2025. It reads medical documents and daily metrics like sleep and exercise, then explains what it sees in plain language.

**[Dish Discovery](https://github.com/shreyamek/Dish-Discovery).** A recipe search app in React and Firebase, from a group project at UT Dallas. I wrote the tests for the search, FAQ and popular recipes pages.
